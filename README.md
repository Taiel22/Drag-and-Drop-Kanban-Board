# 📋 Simple Kanban Board

A simple and lightweight **Kanban Board** built with HTML, CSS, and JavaScript. It allows users to organize tasks by dragging and dropping cards between different workflow stages.

## ✨ Features

- 📋 Simple Kanban-style task management
- 📝 Three workflow columns:
  - **To Do**
  - **In Progress**
  - **Done**
- 🖱️ Drag and drop task cards
- 🔄 Move tasks between any available column
- 🎯 Visual indication when dragging over a column
- 📱 Responsive layout for smaller screens
- ⚡ Lightweight and fast
- 🚫 No frameworks or build tools required

## 🖥️ Preview

The application provides a simple three-column Kanban board where tasks can be moved between **To Do**, **In Progress**, and **Done** using drag and drop.

## 🛠️ Built With

- **HTML5** – Structure of the Kanban board
- **CSS3** – Layout, styling, animations, and responsive design
- **JavaScript** – Drag-and-drop functionality
- **HTML5 Drag and Drop API** – Moving task cards between lists
